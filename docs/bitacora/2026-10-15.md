# Bitácora — 2026-10-15

Se inicia BtoHabitos como aplicación nueva e independiente para el proyecto académico final. El directorio se comprobó inexistente antes de crearlo. Ámbito personal/laboratorio; usuarios y datos sintéticos. Se prepara gobernanza neutral, especificación, plan, tareas, modelo de datos, contratos y encargos de construcción separados.

Decisiones propuestas: Flutter/GetX con Dio, token en almacenamiento seguro, favoritos en Hive por cuenta, servidor FastAPI/SQLite y proveedor de IA compatible con OpenAI llamado solo desde el servidor. No hay mapas ni copia de otra aplicación.

La implementación no se inicia durante esta preparación. No se crean remoto, servicios, credenciales, cuentas, bases ni envíos. Las pruebas de producto, el modelo real, Android y la entrega quedan pendientes de ejecución y evidencia en sus lotes.

Validación del alta: comprobar verificadores SDD, rutas de enlaces, ausencia de secretos/rutas privadas, rama main, commit basal y ausencia de remotos. El resultado y el identificador del commit se comunicarán al coordinador para el mapa de proyectos y el registro durable.
